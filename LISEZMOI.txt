CACHE DU NAVIGATEUR — À LIRE AVANT DE CRIER AU BUG
--------------------------------------------------
  Les navigateurs gardent en mémoire l'ancienne feuille de style.
  Après une mise à jour, une page peut donc s'afficher avec le nouveau
  HTML mais l'ancien CSS : icônes géantes, blocs déformés, couleurs
  incohérentes. Le site n'est pas cassé, le navigateur est en retard.

  Deux réflexes :

  1. Rechargement forcé      Ctrl + F5   (Windows)
                             Cmd + Maj + R  (Mac)
     Ou testez d'abord en navigation privée.

  2. Numéro de version
     Les pages appellent  assets/style.css?v=2  et  assets/app.js?v=2
     À CHAQUE fois que vous modifiez le CSS ou le JS, incrémentez ce
     numéro dans les 13 fichiers HTML (?v=3, puis ?v=4...).
     Rechercher/Remplacer :   ?v=2   ->   ?v=3
     Les visiteurs recevront alors la nouvelle version immédiatement.


MISE EN LIGNE (cPanel Namecheap)
--------------------------------
  1. cPanel : https://cleiptv.site/cpanel
  2. File Manager > public_html
  3. Supprimez le default.html de démonstration s'il existe.
     Si vous remplacez une version précédente, supprimez aussi
     l'ancien dossier assets/ avant d'extraire.
  4. Upload de cleiptv-site.zip
  5. Clic droit sur le zip > Extract (directement dans public_html,
     avec le dossier assets à côté — pas dans un sous-dossier)
  6. Supprimez le zip
  7. Ouvrez https://cleiptv.site en navigation privée et testez
     chaque entrée du menu

  Le .htaccess est masqué par défaut : Settings > Show Hidden Files.


CERTIFICAT SSL
--------------
  cPanel > SSL/TLS Status > Run AutoSSL. Une fois le cadenas visible,
  décommentez le bloc « Forcer le HTTPS » dans .htaccess.


À COMPLÉTER AVANT LA MISE EN LIGNE
----------------------------------
  1. NUMÉRO DE TÉLÉPHONE
     +1 661-541-3954 est un exemple, présent dans l'en-tête, le pied
     de page et le bouton d'appel de chaque page.
     Rechercher/Remplacer dans tous les .html :
       - texte affiché : +1 661-541-3954
       - liens d'appel : tel:+16615413954

  2. TARIFS (index.html, section TARIFS)
     Sur chaque formule :
       data-base   = prix pour UNE connexion
       data-months = nombre TOTAL de mois d'accès, mois offerts compris
                     (Gold : 15 + 3 = 18)
     data-discount sur « pricing-grid » = remise par connexion
     supplémentaire (0.15 = -15 %).
     Le prix affiché, le « soit X € par mois » et le récapitulatif de
     commande se recalculent automatiquement.

     Les tarifs sont repris de votre modèle mais convertis en euros.
     Vérifiez-les avant la mise en ligne.

  3. CLÉ API TMDB
     Visible dans assets/app.js, donc publique. Révoquez l'actuelle sur
     votre compte TMDB, créez-en une nouvelle et remplacez TMDB_KEY.

  4. PAGES LÉGALES
     Champs surlignés en jaune à remplacer (raison sociale, SIRET,
     adresse, hébergeur, médiateur de la consommation...).
     Supprimez ensuite le bandeau jaune en haut de chaque page.

  5. FORMULAIRE DE COMMANDE
     Le bouton « Continuer vers le paiement » affiche un message local.
     Dans assets/app.js, un commentaire indique où brancher votre
     back-end, un e-mail ou un lien WhatsApp.

  6. ARTICLES DU BLOG
     Trois articles sont fournis. Pour en ajouter, dupliquez un fichier
     d'article, changez le contenu, puis ajoutez sa carte dans
     blog.html et dans la section blog de index.html.


MODIFIER LE DESIGN
------------------
  Couleurs, polices, espacements : bloc « :root » en haut de
  assets/style.css. Une modification s'applique à toutes les pages.
  N'oubliez pas d'incrémenter le ?v= (voir « Cache du navigateur »).
