------------------------------------

  2. Passez une commande de test
  3. Notez le message d'erreur rouge qui apparaît

  Vérifiez aussi que l'ancien déploiement (AKfycbw5L3ncry...)
  est bien archivé dans Déployer > Gérer les déploiements, pour
  éviter toute confusion entre les deux.

OÙ METTRE LE SITE EN LIGNE
--------------------------
  Vercel      -> lisez VERCEL.txt (vercel.json est prêt)
  Namecheap   -> section cPanel ci-dessous (.htaccess est prêt)


MISE EN LIGNE SUR NAMECHEAP (cPanel)
------------------------------------
  1. cPanel > File Manager > public_html
  2. Supprimez l'ancienne version : les .html et l'ancien assets/
  3. Upload du zip, clic droit > Extract, puis supprimez le zip
  4. Settings > Show Hidden Files : vérifiez la présence de .htaccess
  5. Ouvrez le site en navigation privée

  Si les pages intérieures renvoient une 404, demandez au support
  Namecheap d'activer mod_rewrite.


CACHE DU NAVIGATEUR
-------------------
  Les pages appellent assets/style.css?v=7 et assets/app.js?v=7.
  À CHAQUE modification du CSS ou du JS, incrémentez ce numéro dans
  les 13 fichiers HTML (Rechercher/Remplacer ?v=7 -> ?v=8).
  Sinon vos visiteurs gardent l'ancienne version pendant une semaine.

  Pour vérifier vous-même : Ctrl + F5, ou navigation privée.

À COMPLÉTER
-----------
  1. NUMÉRO DE TÉLÉPHONE
     +33 6 12 34 56 78 est un exemple, présent dans l'en-tête, le
     pied de page et le bouton d'appel de chaque page.
     Rechercher/Remplacer dans tous les .html :
       - texte affiché : +33 6 12 34 56 78
       - liens d'appel : tel:+33612345678
     Pensez aussi à ORDER_PHONE dans assets/app.js et à PHONE dans
     apps-script.gs.

  2. TARIFS (index.html, section TARIFS)
     data-base   = prix pour UNE connexion
     data-months = nombre TOTAL de mois d'accès, mois offerts compris
     data-discount sur « pricing-grid » = remise par connexion (0.15)
     Les tarifs viennent de votre modèle mais sont en euros :
     vérifiez-les avant de communiquer dessus.

  3. CLÉ API TMDB
     Visible dans assets/app.js, donc publique. Révoquez l'actuelle
     sur votre compte TMDB, créez-en une nouvelle, remplacez TMDB_KEY.

  4. PAGES LÉGALES
     Champs surlignés en jaune à remplacer (raison sociale, SIRET,
     adresse, hébergeur, médiateur de la consommation...).
     Supprimez ensuite le bandeau jaune en haut de chaque page.
