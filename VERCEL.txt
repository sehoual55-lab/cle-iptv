================================================================
  CLÉ IPTV — Mise en ligne sur Vercel
================================================================

  vercel.json est déjà dans le dossier : les adresses propres
  ( /appareils au lieu de /appareils.html ) fonctionnent
  automatiquement, sans rien configurer.

MÉTHODE 1 — LIGNE DE COMMANDE
-----------------------------
  1. Installez Node.js depuis https://nodejs.org (version LTS)
  2. Ouvrez un terminal DANS le dossier décompressé
  3. Tapez :
        npm i -g vercel
        vercel login
        vercel --prod
  4. Répondez : nom du projet, puis « ./ » pour le dossier.

MÉTHODE 2 — VIA GITHUB
----------------------
  1. Créez un dépôt sur https://github.com/new
  2. Envoyez-y le CONTENU du dossier (index.html et assets/ à la racine)
  3. Sur https://vercel.com/new : Import Git Repository
  4. Framework Preset : « Other », aucune commande de build, Deploy

  Chaque modification envoyée sur GitHub met le site à jour.

BRANCHER cle-iptv.store
-----------------------
  1. Vercel : Project > Settings > Domains > Add
  2. cle-iptv.store  puis  www.cle-iptv.store
  3. Créez les enregistrements DNS indiqués par Vercel chez
     Namecheap (Domain List > Manage > Advanced DNS). En général :
        A      @      76.76.21.21
        CNAME  www    cname.vercel-dns.com
     Les valeurs affichées par Vercel priment sur cet exemple.
  4. HTTPS automatique après propagation.

  ATTENTION : un domaine ne pointe que vers un seul hébergement.
  Testez d'abord sur l'adresse .vercel.app.

DIFFÉRENCES AVEC NAMECHEAP
--------------------------
  - .htaccess est ignoré par Vercel ; vercel.json prend le relais.
    Gardez les deux, chacun sert un hébergeur.
  - .vercelignore empêche la publication des fichiers d'aide.
  - Numéro de version ( ?v=7 ) : à incrémenter dans les 13 fichiers
    HTML à chaque modification du CSS ou du JS.
