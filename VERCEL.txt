================================================================
  CLÉ IPTV — Mise en ligne sur Vercel
================================================================

  Le dossier contient déjà vercel.json : les adresses propres
  ( /appareils au lieu de /appareils.html ) fonctionneront
  automatiquement, sans rien configurer.


MÉTHODE 1 — GLISSER-DÉPOSER (la plus simple, 2 minutes)
-------------------------------------------------------
  1. Créez un compte sur https://vercel.com (gratuit).
  2. Allez sur  https://vercel.com/new
  3. En bas de la page, cliquez sur l'onglet ou le lien
     « Deploy a template » puis cherchez l'option d'import
     manuel — ou plus simple, utilisez la méthode 2.

  Si votre interface Vercel propose une zone
  « Drag and drop your project folder », déposez-y le dossier
  décompressé (pas le fichier .zip).


MÉTHODE 2 — EN LIGNE DE COMMANDE (la plus fiable)
-------------------------------------------------
  1. Installez Node.js depuis https://nodejs.org (version LTS).
  2. Ouvrez un terminal dans le dossier décompressé.
  3. Tapez ces commandes, l'une après l'autre :

        npm i -g vercel
        vercel login
        vercel --prod

  4. Répondez aux questions (le nom du projet, puis « ./ » pour
     le dossier). Vercel vous donne une adresse en .vercel.app.


MÉTHODE 3 — VIA GITHUB (recommandée si vous modifiez souvent)
-------------------------------------------------------------
  1. Créez un dépôt sur https://github.com/new
  2. Envoyez-y le contenu du dossier décompressé.
  3. Sur https://vercel.com/new, cliquez « Import Git Repository »
     et sélectionnez ce dépôt.
  4. Framework Preset : « Other ». Ne remplissez aucune commande
     de build. Cliquez « Deploy ».

  Ensuite, chaque modification envoyée sur GitHub met le site à
  jour automatiquement.


BRANCHER VOTRE DOMAINE cle-iptv.store
-------------------------------------
  1. Dans Vercel : Project > Settings > Domains > Add
  2. Saisissez  cle-iptv.store  puis  www.cle-iptv.store
  3. Vercel affiche les enregistrements DNS à créer.
     Chez Namecheap : Domain List > Manage > Advanced DNS.

     En général :
        Type A     @      76.76.21.21
        Type CNAME www    cname.vercel-dns.com

     Vérifiez toujours les valeurs affichées par Vercel :
     elles priment sur cet exemple.

  4. Comptez de quelques minutes à quelques heures de propagation.
     Le certificat HTTPS est créé automatiquement par Vercel.

  ATTENTION : un domaine ne peut pointer que vers un seul
  hébergement. Si le site tourne déjà chez Namecheap, il basculera
  sur Vercel une fois les DNS modifiés.


CE QUI CHANGE PAR RAPPORT À NAMECHEAP
-------------------------------------
  - .htaccess est ignoré par Vercel : c'est vercel.json qui prend
    le relais. Gardez les deux fichiers, chacun sert un hébergeur.
  - .vercelignore empêche la publication des fichiers d'aide
    (apps-script.gs, GOOGLE-SHEET.txt, LISEZMOI.txt).
  - Le cache est géré par vercel.json. Le principe du numéro de
    version ( ?v=5 ) reste valable : incrémentez-le dans les 13
    fichiers HTML à chaque modification du CSS ou du JS.
